# 思辨生态穹顶 · 会跟你辩论的 AI 思辨陪练

《软件工程》2026-2027 第一学期课程报告与界面原型资料。

## 项目概述

一个能跟学生打三轮质询的 AI 陪练：它不讲课、不给答案，只做一件事——把论证当场拆开。
AI 对手逐轮反驳，裁判逐轮给出「站得住 / 部分站得住 / 没站稳」与分数，并把逻辑谬误用红线
和序号标回原句；每场结束生成复盘报告并写入能力档案，下一场按高频谬误排训练重点。

- 八类谬误知识库，24 道判据题，每条判语可检索回依据
- 自建 40 条标注集上判据命中率 97.5%
- 单场模型成本约 0.04 元（含重试 0.07 元）
- 学生、教师两种角色：学生练与看档案，教师看班级概览与逐轮记录
